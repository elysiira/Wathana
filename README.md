## Setup

This project is written using the Flutter framework.

- [Learn Flutter](https://docs.flutter.dev/get-started/learn-flutter)
- [Write your first Flutter app](https://docs.flutter.dev/get-started/codelab)
- [Flutter learning resources](https://docs.flutter.dev/reference/learning-resources)

To setup the development environment :
- Follow [these instructions](https://docs.flutter.dev/install/quick)
- In Android Studio install a device. I am testing this project with a Pixel 8 and the Andoid API 34 (UpsideDownCake).
- Follow [these instructions](https://www.glukhov.org/post/2022/flutter-install/) to install kvm and enable virtualization, that will speed-up the emulator.

## Launch

- In VSCode select the running device : Open the Command Palette (`Control` + `Shift` + `P`) and type `flutter:`. Select Chrome or your Android device.
- Go to the `Run & Debug` tab. You can launch the app.
- Modify files.
